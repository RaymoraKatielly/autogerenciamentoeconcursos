# Autogerenciamento de Concursos

Site institucional desenvolvido para organização e acompanhamento de estudos voltados a concursos públicos.

## Objetivo
Auxiliar no planejamento, organização de conteúdos e visualização do progresso nos estudos.

## Tecnologias
- HTML5
- CSS3

## Funcionalidades
- Estrutura de páginas informativas
- Organização de conteúdo por seções
- Layout simples e funcional
- Design responsivo

## Contexto
Projeto desenvolvido como aplicação prática de organização de informações e estruturação de site institucional.
